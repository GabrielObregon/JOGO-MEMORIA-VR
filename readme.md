# Jogo da Memória em Realidade Virtual

Este projeto consiste em um Jogo da Memória desenvolvido em Realidade Virtual (VR) utilizando o framework A-Frame, baseado em WebXR.

A aplicação permite interação tanto em modo desktop (mouse) quanto em modo VR (controles com laser).

## Funcionalidades

- Geração dinâmica das cartas
- Embaralhamento automático
- Animação de virar carta
- Sistema de tempo (cronômetro)
- Contador de tentativas
- Tela de vitória animada
- Efeito de confetes
- Suporte a Realidade Virtual (WebXR)
- Compatibilidade com desktop

## Tecnologias Utilizadas

- HTML5
- JavaScript
- A-Frame
- WebXR

## Como Executar

1. Clone o repositório:

   git clone https://github.com/GabrielObregon/JOGO-MEMORIA-VR.git

2. Acesse a pasta do projeto.

3. Abra o arquivo `index.html` em um navegador compatível, como Google Chrome ou Microsoft Edge.

4. Para utilizar em VR, clique em "Enter VR".

## Objetivo

Demonstrar a integração entre lógica de jogo em JavaScript, manipulação de objetos 3D, interação por raycasting e construção de um ambiente imersivo em Realidade Virtual.

## Observação

O arquivo `trofeu.glb` deve estar na mesma pasta que o `index.html` para que o modelo 3D seja carregado corretamente.
